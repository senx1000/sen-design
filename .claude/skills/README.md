# SEN Skills（実行層 / アダプタ）

このディレクトリは、SEN Design の原則を**実行可能な器**にした Skill を置く場所。
能力（共通層＝canon の原則・仕様）と、スキル（実行層＝ここ）を分ける（第11.3 二層化）。
canon 本体（第1部25条）は抽象・人間の領域につき、Skill からは参照するだけで改変しない（第7条）。

| Skill | 役割 | 主な接続 |
|-------|------|---------|
| `sen-delegate` | タスクを別チャット／別LLMへ委譲する「1コピペ依頼文」を生成 | CLAUDE.md 委譲ルール／`SEN_Delegation_Template_v1.md`／第5章・5.5・第11.3 |
| `sen-worktable` | 非エンジニアが Claude Code を「AI作業台」にする初期セットアップを提案 | 第25条・第11章・第3部 5.5・5.6 |

起動：`/sen-delegate`, `/sen-worktable`（またはその意図が会話に現れたら自動想起）。

新しい Skill を足す時は、対応する canon の条項・章を「参照」節に明記し、
共通層（仕様）を改変せず実行手順だけをここに置く。
