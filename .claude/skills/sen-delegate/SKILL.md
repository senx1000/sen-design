# sen-delegate — 1コピペ委譲依頼文ジェネレータ

## Purpose

人間は抽象（何を・なぜ・どこまで）を渡す。モデルは具体（どう）を実装する（第7条・第17条）。
この Skill は、その翻訳の器＝**完成した依頼文**を作る。
ユーザーは要点だけ伝える。**完成形は Claude が作る。** 聞かれなくても、この形で出す。

## Non-negotiables（厳守）

1. **単一コードブロックに、完成した依頼文を丸ごと入れる。** ユーザーは中身を編集せず、
   そのままコピペするだけで済むこと（脳死コピペ）。
2. **プレースホルダを残さない。** `<対象パス>` のような空欄を作らない。会話から分かる情報は
   全て埋める。本当に不明な点だけ、コードブロックの**外**で最小限に確認する（理想は確認ゼロ）。
3. **自己完結させる。** 受け取る側はこのリポジトリもテンプレートも持っていない前提。
   必要な制約・原則は依頼文の中に直接書き下す。「第5条」等の参照だけで済ませず一言で意味も添える。
4. **モデル非依存に書く（第11.3 共通層）。** 特定モデルのツール名・口調を依頼文本体に埋め込まない。
   モデル固有の調整が要るなら、コードブロックの**後**に「アダプタ補足」として短く別記する。
5. **命令ではなく成功条件を渡す（第3部 5.5）。** 手順を指図せず、「何を満たせば完了か」を
   検証可能な形で列挙する。実行者がそこへループできるゴールを与える。

## Inputs（会話から吸収する。足りない分だけ最小確認）

- タスクの要点（何を・なぜ）
- 対象リポジトリ／Vault／パス、既存構造・命名規則（不明なら「実行者自身に `ls` 等で探索させる」設計で吸収）
- 守るべき制約、触ってはいけない箇所、参照すべき資産
- 委譲先（Codex／別Claude／ローカル等。分かれば末尾のアダプタ補足に反映）

## Workflow

1. 会話から §Inputs を可能な限り埋める。埋まらない核だけを1〜2問、コードブロックの外で確認。
2. 下の共通層構造で依頼文を組み立てる（目的／文脈／成果物／制約／評価基準／禁止事項／引き継ぎ）。
3. 制約には必ず SEN の3原則を一言意味つきで書き下す：
   - データ主権（第5条）：機密・個人情報は外部に出さない。境界線の内側で処理。
   - 摩擦配置（第4条）：閲覧・新規作成は自動可／既存編集・依存追加・コミットは確認／削除・破壊的操作・外部書き込み・課金は必ず停止。
   - 抽象不可侵（第7条）：設計判断・哲学・優先順位は実行者が勝手に変えない。迷ったら実装を止めて問いを返す。
4. 評価基準は §5.5 に従い**検証可能なゴール**として列挙（目的充足／既存整合／モデル非依存で再利用可／タスク固有条件1〜3個）。
5. 単一コードブロックで出力。必要なら後にアダプタ補足を短く別記。

## Output（このコードブロックの形で出す）

```markdown
# 依頼：<タスク名>

## 0. メタ
- 依頼者：<人間 / 役割>
- 実行者：<任意の LLM>
- 抽象度：<実装 / 調査 / 整理 / 設計>

## 1. 目的（なぜ・何を）
<一文。世の中／プロジェクトの何の必要に応えるのか>

## 2. 文脈
- 対象：<パス・既存構造・命名規則。不明なら実行者に探索させる指示>
- 前提・制約：<守る規約、依存、触ってはいけない箇所>
- 参照資産：<過去の手順・調査・設計メモ>

## 3. 成果物
- <作成／変更するファイルと役割・形式。1依頼1目的で完結>

## 4. 制約・原則
- データ主権：機密は外部に出さない、境界線の内側で処理
- 摩擦配置：閲覧/新規=自動、既存編集/依存追加/コミット=確認、削除/破壊的/外部書込/課金=停止
- 抽象不可侵：設計・哲学・優先順位は変えない。迷ったら止めて問いを返す

## 5. 評価基準（成功条件＝検証可能なゴール）
- [ ] 目的（1.）を満たす
- [ ] 既存の構造・命名規則に整合
- [ ] モデル固有前提に依存せず、次のモデルでも再利用可能
- [ ] <タスク固有の合否条件 1〜3個>

## 6. 禁止事項
- 指示にない範囲への波及的変更（大規模リファクタは事前確認）
- 文脈（2.）に無い前提の捏造
- 評価基準（5.）未充足のままの「完了」報告

## 7. 引き継ぎ（出力フォーマット）
- 変更点の要約（何を・なぜ）
- 評価基準（5.）各項目の自己チェック結果
- 勝手に決めた箇所の明示（後で人間が視差を当てる）
- 次の一手（あれば）
```

必要時のみ、コードブロックの後に：

> **アダプタ補足（<委譲先>向け）**：<実行環境・対象パス・ツール権限・分割方針など、モデル固有の薄い変換だけ>
